# SakuSkill

> Platform Marketplace Skill & Micro-Services Mahasiswa

SakuSkill adalah platform marketplace jasa mikro dan pertukaran keahlian (*skill barter*) antarmahasiswa berbasis kampus yang aman, terverifikasi, dan transparan.

---

## 📌 Status Repositori & Cabang
- **`main`**: Cabang rilis utama (versi bersih dan stabil).
- **`develop`**: Cabang aktif untuk perancangan dan pengembangan aplikasi yang dimulai dari awal.
- **[`referensi`](https://github.com/luminariadev/sakuskill/tree/referensi)**: Cabang arsip yang menyimpan seluruh kode awal, blueprint arsitektur, dan implementasi sebelumnya sebagai rujukan teknis.

---

## 🚀 Alur Pengembangan
Seluruh perancangan arsitektur dan pengembangan fitur baru dilakukan pada cabang `develop`. Implementasi kode dan dokumentasi teknis versi rujukan sebelumnya tetap dapat ditinjau kapan pun di cabang `referensi`.
